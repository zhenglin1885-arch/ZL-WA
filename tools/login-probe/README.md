# ZL-WA 独立登录验证 0.1.0

这是独立实验工具，不是 ZL-WA 更新包，也不是 WhatsApp 官方桌面接口。
后端为 Baileys 7.0.0-rc14，以 WebSocket 实现 WhatsApp 多设备连接，无内嵌 WhatsApp 网页。
它仍属于非官方 WhatsApp 协议实现，不能保证解决特定账号的配对问题，也不能保证账号风险或长期兼容性。优先使用测试账号。

## Windows 使用

1. 解压整个 ZIP 到单独文件夹，运行 `ZL-WA Login Probe.exe`，不要覆盖原软件。
2. 点击“开始 / 恢复登录”，使用手机 WhatsApp 的“已关联设备”扫码。
3. 电脑显示连接建立后，让另一个测试账号向它发送文字，确认下方出现消息。
4. 手动输入测试收件人的国际号码和文字，发送一次，请收件人在手机确认实际收到。
5. 关闭工具，重新打开并点击“开始 / 恢复登录”，确认无需扫码恢复。
6. 如果仍失败，点击“复制诊断”，报告电脑页面、手机关联状态及收发实际结果。

只有扫码、收发、重启恢复全部实测通过，才能说明新连接路线可用于这个账号。
手机出现已关联设备或程序连接建立，单独都不代表全部成功。

## 数据和行为

- 独立目录 `%APPDATA%\ZL-WA-Login-Probe`。登录密钥在 `auth` 子目录，属于敏感数据，请勿分享、上传或复制给他人。
- 不读取、清理或改写 ZL-WA 的账号数据。一次只支持一个测试账号。
- 不导入原聊天历史；当前窗口最多保留 30 条收到的通知消息，关闭即不再展示。
- 没有群发、群管理、语音或翻译功能；不会自动向任何人发送测试消息。
- 手动发送没有确认结果时绝不自动重发。用户再次发送前需先检查对方是否收到。
- 断开或关闭只结束连接，不退出手机关联、不自动删除密钥。退出关联可在手机端操作。
- 诊断只包含固定状态、时间、断开数字代码及计数，不含二维码、密钥、手机号、消息内容。
- 网络直接通过 Node WebSocket 建立，工具不设置应用代理；不更改系统网络。

## 验证范围

自动测试覆盖生命周期、凭据写入失败、重连上限、重复启动、迟到二维码、输入检查、未知发送结果和诊断脱敏。
Windows 打包后执行实际原生启动、隔离渲染 IPC、凭据落盘再读取、进程重启检查。
开发云端的一次实际连接尝试以 408 超时结束，未取得二维码。这不能证明用户电脑的连接结果，也不能视为已修复登录。
这些测试不等于真实手机配对成功。发布时真实问题账号配对、同步、收发和登录保持仍待用户验证。
Windows 包未签名。此次不发布 Mac 包，不修改现有正式版资产。
