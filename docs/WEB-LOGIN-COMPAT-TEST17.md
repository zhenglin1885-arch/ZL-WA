# ZL-WA 7.3.9 test17 · 原网页登录兼容

完全退出旧版后安装。仍使用原 WhatsApp 网页，在原账号内扫码或使用其“使用电话号码登录”入口。不增加新连接方式，不打开另一种登录窗口，不迁移、删除或导入任何账号认证资料，不改代理、备注或其他设置。

此包移除了之前已取消的“使用新连接（测试）”及“打开官方登录窗口”，包含它们的旧测试版不会被自动更新；本包也不触发正式版更新。保留原群发从下到上、默认 Enter/可选 Shift+Enter、翻译、客户备注、群管理、点赞和任务队列规则。

## 本轮兼容修改

- 对已经由官方页面初始化的新 BackendEventBus 读取连接状态，兼容其同步就绪事件。旧版 Socket 接口仍按原路径工作。
- 不强制加载尚未初始化的 Meta 模块，不改写原生 require、事件总线、WebSocket、浏览器历史或存储。
- SDK 内部以兼容接口订阅新版事件；保留旧版分支和先前 LID 修正。连接、主流及页面尚未就绪或已暴露的关键同步检查未完成时不发送。
- 修复启动恢复中的异步检查问题：等待结果后必须仍是同一有效窗口、仍为需要恢复的错误文档才允许重载。二维码、聊天或其他正常表面不会因旧恢复任务而刷新。
- 原诊断按钮可复制最近的原生配对/电话号码关联事件；页面导航后保留同一会话的有限事件历史。只保留白名单事件和状态，不复制二维码、配对码、号码、密钥、Cookie、正文、原始错误对象或网页 URL。

已对原 SDK 的真实模块工厂、新旧接口、同步等待、断线期间的就绪检查、脱敏与跨页面事件、防误重载、编译后的可序列化函数及原功能进行受控测试。测试并不等于故障账号已通过真实手机关联；本版尚需用户实际扫码验收。若仍返回二维码，请立即在原“代理”面板点击“检查并复制发送诊断”，提供含 nativeConnection 和 nativeTransitions 的日志；不需要进入开发者工具。
