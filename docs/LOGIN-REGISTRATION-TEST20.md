# ZL-WA 7.3.9 test20 · 原网页注册阶段诊断

这是诊断包，尚未验证真实账号恢复登录。原 WhatsApp 网页、发送、群管理、备注、翻译、代理和队列逻辑保持原样。

本次只监听已初始化的官方 WAWebODSObserver 事件，筛选 12 个固定注册阶段，包括原生配对完成、注册开始、缺少设备信息/配对元数据、nonce 解密/解析失败、认证交换尝试/成功/失败。不调用 WAWebODS 懒加载入口，不主动触发配对或重新加载，不读取密钥、nonce、令牌、手机号或原始错误内容。离开页面时仅移除自己的监听。

connection.format=6，nativeConnection.registrationEventsObserved 表示监听器是否成功安装。事件缺失仅表示没有观察到，不能证明官方流程没有执行。注册阶段经过原隔离桥留存在当前账号的有限日志中，最多 64 条；导航后仍可导出。515 仍只代表中间交接，不能作为登录成功依据。
