# 主窗口启动与恢复（待发布）

- 从本地文件路径生成经过编码的界面 URL，避免安装目录中的 `#`、`%`、空格和非 ASCII 字符被当成地址片段或转义序列。主进程接住加载失败的 Promise，只记录错误码，不记录用户路径。
- 主文档加载失败也会启动界面检查；持续缺少根节点或根节点隐藏时，复查后按既有冷却规则恢复一次。恢复重新打开已知的应用文件，不重新加载错误页；中断导航和子页面失败不触发主界面恢复。
- React 在 DOM 解析完成后初始化，不等待所有图片、字体或子页面完成加载。
- Windows 任务栏图标的右键任务增加 `Reload UI` 和 `Restart without GPU`。界面重载、移动窗口和退出不再等待界面加载完成；重载可中止卡住的导航并重新打开本地界面。
- `Restart without GPU` 是用户手动选择的单次软件渲染启动，保留现有启动参数和账号数据路径，不修改保存的硬件加速偏好。

验证包含真实 Electron 的特殊安装路径加载、失败文档恢复、渲染进程崩溃恢复、保留本地存储、避免重复重载，以及 DOM 就绪初始化的回归测试。当前环境不是 Windows 11，未将本地复现视为用户机器的确定根因；显卡驱动问题仍需异常时的诊断或软件渲染启动结果确认。

## 托盘和主进程初始化

- Windows 的通知区域显示开关只决定已注册图标是否展示，不能替代软件的“启用系统托盘”设置。正常启动仍尊重软件内的设置。
- 托盘注册提前到账号功能初始化之前，避免读取账号工具配置报错时连原生恢复入口都尚未创建。
- 主进程功能初始化失败时停止自动重载，不打开缺少代理或认证接口的半初始化界面。直接显示原生错误对话框，提供 `Export Diagnostics` 和退出选项，导出完成后才退出；保留原配置和账号数据。错误诊断只记录固定代码，不包含任意异常正文或密码。
- 该分支解决的是代码中的启动失败处理缺口，不能仅凭用户未看见托盘图标就认定其配置文件已经损坏。
