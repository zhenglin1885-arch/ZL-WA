# 新连接整合测试版 test15（Windows）

这是在 ZL-WA 内接入独立协议连接的首个整合测试版。此前独立验证工具的扫码和同步已获得用户确认；整合版仍需要问题账号的真实收发、群操作和重启验收。它不是 WhatsApp 官方电脑版接口，也不是正式版升级发布。

## 使用

1. 完全退出 ZL-WA 和独立登录验证工具，再安装此测试包。
2. 在需要测试的 WhatsApp 账户卡片菜单中选择“使用新连接（测试）”。原网页方式是默认值，其他账号不自动切换。
3. 在软件里的新聊天窗口扫码。新连接的资料独立保存，不读取或迁移独立验证工具的密钥，也不删除原网页会话。
4. 检查聊天同步、文字收发和语音；关闭软件重新打开，检查该账号能否恢复连接。
5. 群发、进群、退群、群发言权限、点赞继续从原右侧入口操作。先用少量测试对象验证。所选群组仍按列表从下到上发送。
6. 如需回退，在账号菜单选择“切回网页连接”。原来的网页 Cookie、数据库及其他账号保留。

## 此次接入

- 每账号独立的后端进程、凭据和消息缓存；后台接收、休眠断开、退出保存与恢复；身份变化时隔离旧消息。
- 聊天列表、按号码打开私聊、文字、图片、视频、语音和文件。语音转为 Ogg/Opus；视频转为 MP4/H264/AAC。仍需接收端验证实际可用性。
- 全局 Enter / Shift+Enter 设置、输入法和长按防误发；引用、编辑和撤回；收发翻译、发送译文预览与修改、禁止中文。
- 原有群发队列和群组队列：原有倒序、间隔、定时、提及所有人、失败策略、限流冷却与结果核验继续使用；发送未知结果停止并保留编号，不自动重发。
- 客户资料、备注和本地置顶沿用原有存储；聚合会话、已读、文字/图片匹配点赞和当前已同步消息保存接入新连接。
- 诊断不导出账号号码、二维码、正文或密钥。

## 明确限制

- 此轮新连接只支持直连。启用了代理时会明确拒绝连接，不会静默直连；原网页方式保留原有代理功能。
- 新连接采用自己的聊天界面，不是 WhatsApp 官方网页版。官方网页内的通话、状态、频道、完整通讯录/历史浏览等界面没有整体移植。
- 新连接只保留每个聊天最近 300 条、总量约 20000 条消息；界面和现有历史保存接口每次读取其中最近 200 条。深历史回补、完整媒体历史备份、图片/视频等复杂引用、官方消息表情的所有显示细节，尚不能视为与网页版等价。
- 原网页发送记录的消息编号与新连接不同，旧记录保留，旧记录的核验/编辑/撤回应切回原网页方式处理；不会因此自动重发。
- 点赞/引用查找以新连接当前已同步消息为范围；无法确认匹配时不提交。服务器回执只代表服务器确认，仍应由收件人确认收到。
- 真实服务器行为（审批、限流、群管理员权限、撤回时限、媒体兼容性）不能仅凭本地模拟测试判定成功。
- 本次提供 Windows 未签名测试包，不覆盖任何正式版 Release 资产，不发布 Mac。

## 验证

附带 QA-summary.json、GUI-checks.txt、Windows 原生启动报告和 SHA256SUMS.txt。它们区分本地受控界面检查、独立真实进程/编解码检查，以及尚未完成的整合版真实手机验收。

新连接资料位于原应用数据目录的 protocol-accounts 子目录；其中 auth 内是敏感登录凭据，请勿分享。
