# ZL-WA 7.3.9 test16 · 新连接聊天界面

安装前完全退出 ZL-WA。原网页账户不会自动切换；需要在账户菜单选择“使用新连接（测试）”。已使用 test15 新连接的账户沿用原认证资料，本版不会清空或强制重新扫码。

## 本轮修复

- 隔离上游 `div { height: 100% }` 全局样式，解决标题、列表、输入工具条高度异常以及只看见一项聊天的问题。
- 参考 WhatsApp 采用紧凑列表，显示头像、真实聊天名称、时间、备注、客户标记、最后消息和未读数。头像按可见范围限并发读取；对方隐私限制或读取失败时显示占位图。
- 搜索、全部/未读/群聊/归档筛选；备注、置顶操作放入每条聊天的菜单。连接操作放入顶部连接选项。
- 新建聊天使用独立的号码输入；搜索和打开手机号码不再共用输入框。
- 消息使用左右气泡，群消息优先显示已知发言人姓名；保留原始消息与参与者编号供原功能使用。
- 保留账户菜单的放大/缩小，新界面的列表、消息和工具条文字随设置缩放。
- 输入框固定在底部，聊天与列表分别滚动。首次打开定位最新消息；向上阅读时不强制滚动，新消息提示可一键回到底部。
- 设备元数据按实际平台设置。Windows 新关联显示 Windows，而非库默认 Mac OS。手机已保存的旧名称可能保留；此改动不修改认证密钥、协议版本或配对流程，不会强制登出。

## 保持原规则

原网页方式、其他账户、备注资料不变。群发仍按选中群列表从下往上；未知发送结果不自动重发；默认 Enter 发送，Shift+Enter 换行，用户选择反向模式后按其设置执行。原 BulkQueue、GroupQueue、ReactionQueue 没有改动。

## 验证及限制

本版是非官方协议的新连接测试界面，不是官方 WhatsApp Desktop 的接口或网页嵌入，未完整移植官方通话、状态、频道和完整历史等功能。仍仅支持直连，已配置代理时明确拒绝新连接，不会私自绕过代理。

本地受控界面检查包含 65 条聊天、百条历史、1400×900 和 1100×720 窗口、输入栏可见、账户文字缩放与恢复、默认 Enter、可选 Shift+Enter、IME、按住键保护、保持阅读位置、回到最新、筛选、原客户备注和本地置顶、D-C-B-A 原群发队列、未知发送不重发和切回网页保留 Cookie。受控消息均为模拟数据，不能替代真实账号收发验证。

用户反馈 test15 已能关联并同步。本版的真实账号收发、媒体和群操作仍需用户验收；发布时附带成品 Windows 检查报告。Windows 测试包未签名，未修改正式版资产，未发布 Mac。
