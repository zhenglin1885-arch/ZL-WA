# 批量引用回复

“点赞”下方新增“回复”入口。复用群发窗口，增加“匹配内容”和三种规则：完全相同、包含文字、忽略标点和空格后完全相同。

选择账号和会话后，填写匹配内容及要发送的正文或附件，通过确认窗口执行。每个会话在发送时查找当前账号可读历史中最新一条匹配消息，使用 WhatsApp 原生引用框回复，不自动 @原消息发送者。

匹配只读取正文或图片等消息的附言，不读取消息中的旧引用。每页读取200条，最多50页、约20秒；未找到时记录失败原因，不降级为普通发送。每个会话的失败处理继续沿用群发窗口的“遇到失败停止”或“跳过失败继续”选项。

发送前重新检查登录身份、会话归属和原消息内容；目标已删除、编辑或不再匹配时不发送。文本、图片、图文、视频、语音、名片和文件沿用原群发接口，并携带 `quotedMsg`。随机间隔、定时、停止、结果核验、撤回和编辑等已有流程保持原逻辑。未取得发送消息编号的引用回复不会凭普通同文消息猜测成功，也不会自动重发。

普通群发与引用回复共用原有队列及存储，但窗口分别显示各自的记录。回复设置保存在独立的 `replyPreferences` 字段，由 `account-tools-reply-preferences` 通道读写；原 `bulkPreferences` 不变。旧记录没有 `spec.reply`，仍归普通群发。

自动化验证覆盖三种规则、最新消息、多账号身份、跨会话保护、未匹配不发送、附件引用和设置隔离。`scripts/verify-bulk-replies-ui.mjs` 使用合成 WhatsApp 页面，在实际 Electron 窗口中验证双账号群聊/私聊引用、发送确认、原群发隔离及未匹配失败；纳入 `scripts/verify-account-tools-ui.mjs` 完整桌面回归。
