# 批量点赞

本功能独立于群发、群管理、进退群及翻译。右侧“退群”下方的“点赞”按钮打开独立三栏窗口。

## 已确认的范围

- 手动创建一次性任务，不监听未来新消息。
- 账号和群组可多选。同一群按群编号合并显示，只执行所选账号已经加入的群。
- 按输入的原始消息文字匹配，每个账号、每个群只取最新一条。支持完全相同、包含文字、忽略空格和标点后完全相同。
- “匹配文字”右侧可切换“匹配图片”。上传JPG、PNG或WebP参考图并预览，按画面比较以兼容常见压缩和尺寸变化；查找到的图片也会显示预览。每个账号每群仍只取最新一条。切换模式保留原文字和参考图片。
- 参考图片最多20MB、4000万像素，处理及比较均在本机完成。只保存缩略图和画面特征，不上传参考图到翻译或识别服务。图片消息在执行前复核消息编号、媒体哈希和账号身份；较新图片读取失败时，不会擅自选更早的图片。
- 多个表情随机分配给账号群组任务，每条任务只发送一个表情。
- 全部账号共用时间设置。可在指定本机日期时间段内随机安排，也可按统一随机间隔执行；所有点赞任务串行发送。
- 查找和预览不发送表情。启动后锁定预览的消息编号，发送前重新核对身份、群成员状态及消息内容，避免误点其他消息。

## 运行与结果

指定时间段按任务数划分随机时间槽，并打乱账号群组顺序；时间槽至少间隔1秒。请求耗时使任务延迟时仍串行执行，超过结束时间的任务记录失败，不补发。

关闭窗口不停止任务；“开始点赞”右侧的“终止执行”按钮终止后续待发送项，已经提交的请求等待返回。退出软件后暂停，重启不会自动恢复，需要在任务记录中手动继续待执行项。上次已提交但结果未确认的任务不会重发。

查找分页读取该账号可用的群历史，每页200条，最多50页，单次查找约20秒；接口超时另有30秒保护。未找到时显示已查找数量；达到上限会明确显示，不能保证查到该账号尚未同步的历史。

结果分别显示成功、失败、未确认、已停止和等待执行，并保留原始接口原因。接口没有明确成功返回时，会只读核验本账号的实际表情；结果区的“核验未确认结果”也只读取状态，不重发。超时后仍在执行的请求会阻止新点赞请求，避免重叠；不会自动重试未知结果。

## 存储和验证

仅新增用户数据目录的 `reaction-tools.json`，保存设置及最近20批任务（每批最多1000个账号群组对象，总记录不超过5MB）。使用现有主窗口权限校验和原子替换写入，不修改现有配置或缓存文件。

`test/reactions.test.ts`、`test/reactions-runtime.test.ts` 覆盖匹配、排程、去重、停止、超时、身份与持久化；`scripts/verify-reactions-ui.mjs` 通过现有独立测试账号和合成WhatsApp页面验证真实Electron窗口操作。桌面回归入口为 `scripts/verify-account-tools-ui.mjs`。
