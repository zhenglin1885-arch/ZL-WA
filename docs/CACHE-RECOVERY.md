# 缓存目录丢失后的恢复

安装版 AutoSetup 在更新时会清理旧的软件安装目录，因此不要把自定义缓存放在安装目录或其子目录内。例如安装在 `D:\Soft\ZL-WA` 时，可以选 `D:\ZL-WA数据`，不要选 `D:\Soft\ZL-WA\AppData`。本机设置现在会拒绝这种不安全的选择；便携版的数据位置不受该安装版限制影响。

自定义缓存目录统一使用所选文件夹下的 `AppData\Roaming\ZL-WA`。例如选择 `E:\ZL-WA`，实际使用 `E:\ZL-WA\AppData\Roaming\ZL-WA`。旧版 `ZL-WA缓存` 目录仍按原配置读取；重新选择保存文件夹后，在下次重启时校验并迁移账号网页数据，不直接重命名正在使用的目录。开发版使用 `ZL-WADev` 避免混用。

若启动时原目录不可用，修复后的程序会先暂停账号启动，显示恢复入口：

- **重新检查原目录**：适合磁盘暂时离线、随后重新连接的情况。
- **选择已有数据目录**：适合原文件夹被移动，或者已有完整缓存备份。选择包含 `Partitions` 和 `.zl-wa-browser-data.json` 的缓存文件夹。只接受属于当前配置的原数据，拒绝空文件夹或其他配置的数据；若旧数据还在安装目录内，请先完整复制到安装目录以外再选择。
- **使用新目录并重新登录**：原文件夹被删除且没有备份时，先确认需要重新登录，再选择安全位置。程序创建独立新目录，另存旧缓存路径配置，不删除任何旧目录，也不清除账号卡片、群发记录或本机聊天备份。
- **退出软件**：不修改原配置。

恢复操作完成后，程序重新启动，再在打开网页账号前启用正确的缓存目录。不会直接使用空缓存冒充恢复成功。

已经删除的登录 Cookie 和网页数据库无法凭空恢复；HTML 聊天备份可用于查阅聊天，但不能代替 WhatsApp 登录数据。
