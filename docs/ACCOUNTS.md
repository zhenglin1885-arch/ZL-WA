# 分组账户侧栏

本次修改基于 ZL-WA 的 Ferdium 7.2.3 基础版。侧栏参考用户提供的深色账户卡片布局。

## 使用方式

- 点击“新增分组”，输入名称保存。默认分组固定保留，所有没有分组的旧会话和通过原有服务界面添加的会话归入默认分组。
- 每个分组标题显示会话数量；点击标题折叠或展开。折叠不关闭、不卸载其中的会话网页。
- 分组右侧“新增会话”直接创建 WhatsApp 会话，加入当前分组并选中。使用应用内置的 WhatsApp 配方，不依赖在线服务目录来创建。
- WhatsApp 会话固定使用各自的持久化 Session 分区；同一分组不共享登录数据，原有的共享 Session 选项不应用于 WhatsApp。如果此前主动使用共享分区，需要在独立分区中重新扫码；不自动复制共享登录数据。
- 卡片依次显示昵称、手机号码和备注。读取到本人资料时显示 WhatsApp 昵称与头像；尚未读取到号码显示“号码待同步”，头像缺失显示姓名首字占位。
- 点击备注即可编辑；留空显示“暂无备注”。
- 卡片右上角月亮按钮用于手动休眠：关闭该账号的会话网页并释放页面资源，保留分组、备注及登录数据。只有再次点击休眠按钮才会重新加载会话；点击卡片只切换到休眠占位页面。删除其他会话不会唤醒休眠账号。按钮高亮和圆点提示显示休眠状态；休眠期间该页面不实时接收消息。
- 手动休眠不依赖自动休眠设置，也不会被定时唤醒。休眠状态仅用于本次运行；程序重启后按正常启动策略加载会话。
- 所有分组、折叠状态、所属分组、本地昵称、备注和缩放比例通过应用设置保存到当前 ZL-WA 数据目录。
- 分组菜单还支持重命名和删除；删除分组会将会话移到默认分组，保留账号及备注。

## 状态圆点

| 颜色 | 含义                                                           |
| ---- | -------------------------------------------------------------- |
| 绿   | 从 WhatsApp 已登录页面或连接状态读到登录证据                   |
| 红   | 检测到扫码登录页面、未配对或退出登录                           |
| 黄   | 网络异常、掉线冲突、页面错误、封禁等账号异常 |
| 灰   | 已休眠，或正在连接、等待确认状态 |

鼠标悬停圆点可查看文字状态。网页加载成功本身不代表账号已登录。
登录状态是实时观察结果，不把上一次绿点保存为下次启动后的在线证明。
只读取本人资料，不使用当前聊天对象的昵称、号码或头像。WhatsApp 的 LID 身份标识不会作为手机号显示。
资料适配依赖 WhatsApp 网页的当前 DOM/内部模块；网页升级后可能需要维护。

## 卡片菜单

| 操作     | 行为                                                                                                                 |
| -------- | -------------------------------------------------------------------------------------------------------------------- |
| 刷新会话 | 重新加载该会话网页，保留 Session 和登录数据                                                                          |
| 全部已读 | 在已登录的 WhatsApp 内调用读取回执接口，逐个标记已加载模型中的未读聊天；报告成功和失败数，不直接清空侧栏计数伪装成功 |
| 放大10%  | 当前会话缩放增加 10 个百分点，例如 100% → 110%                                                                       |
| 缩小10%  | 当前会话缩放减少 10 个百分点；范围 30%～300%                                                                         |
| 重置窗口 | 当前会话恢复 100% 缩放并滚动到顶部，不删除登录数据，也不调整整个桌面程序的尺寸                                       |
| 移动分组 | 选择目标分组，保留会话、备注和登录数据                                                                               |
| 修改昵称 | 修改本地卡片昵称；留空恢复自动读取的 WhatsApp 昵称，不修改远端 WhatsApp 个人资料                                     |
| 删除会话 | 二次确认后通过原有删除流程移除服务及其本地登录数据；同时清理该卡片偏好                                               |

会话网页尚未打开时，刷新和缩放不可用；未登录或连接异常时“全部已读”不可用。
WhatsApp 网页接口不可用或标记失败时显示原因；不声称未执行的标记操作成功。
“全部已读”会发送实际读取回执；未加载、未同步到网页模型的历史聊天不保证覆盖。

## 验证边界

已在云端实际 Electron 界面验证分组、默认和指定分组新增、卡片选择、备注、昵称、折叠、移动、缩放和菜单操作。
新增、删除时等待会话缓存更新，避免卡片尚未创建就被激活。菜单/弹窗打开时，网页加载完成不会抢走其键盘焦点。
自动测试覆盖分组数据迁移与保存、IPC 可序列化、登录状态分类、手机号与 LID 区分、读取回执与失败报告，以及缓存和焦点回归。
没有扫码登录真实 WhatsApp 账号。本人资料识别和实际聊天读取回执仍需在 Windows 上用真实账号验收。
截图中的“验收账户”等为开发测试会话，不代表真实账号已登录；图中黄点是实际检测到的状态。

## 聊天列表与浅色外观（7.3.2）

WhatsApp 聊天列表顶部增加宽度按钮，点击切换宽窄，也可拖动或用左右方向键微调。各账号分别记住宽度；调整不重载会话。浅色模式的账号侧栏和右侧工具栏采用紫色背景。
