ZL-WA macOS 正式版 7.3.7，应用代码基于现有 v7.3.7 正式版本。

- Apple Silicon（M 系列芯片）：下载 arm64.dmg。
- Intel 芯片：下载 x64.dmg。
- 适用 macOS 12 或以上。打开 DMG 后，将 ZL-WA 拖入 Applications（应用程序）。ZIP 为同架构的备用下载。
- 两种架构均在对应的 macOS 环境通过包内应用启动检查；DMG 与 ZIP 内应用内容一致。

签名说明：此版本使用 ad-hoc 本地签名，没有 Apple Developer ID 签名和 Apple 公证。首次打开可能受到 macOS 安全检查拦截；仅在确认下载来源后，在“系统设置 → 隐私与安全性”中允许打开。

SHA256 校验值与构建验证报告见附件。此 macOS 发布不修改 Windows 安装包。
