ZL-WA macOS 正式版 7.3.7（Intel / x64），应用代码基于现有 v7.3.7 正式版本。

适用 Intel Mac，系统要求 macOS 12 或以上。打开 DMG 后，将 ZL-WA 拖入 Applications（应用程序）；ZIP 为备用下载。

已在 Intel macOS 环境验证安装后启动、界面、设置和本地会话初始化；已核对 DMG/ZIP 内容、签名、SHA256、397 个应用模块及 16 个服务配置包。

签名说明：此版本使用 ad-hoc 本地签名，没有 Apple Developer ID 签名和 Apple 公证。首次打开可能受到 macOS 安全检查拦截；仅在确认下载来源后，在“系统设置 → 隐私与安全性”中允许打开。

Apple Silicon（M 系列）原生安装包暂未发布：多次构建因 GitHub 无法分配 ARM 构建机器而失败。本次提供的安装包为 Intel 架构。

SHA256 校验值与构建验证报告见附件。
