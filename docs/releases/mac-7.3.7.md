ZL-WA macOS 正式版 7.3.7，应用代码基于现有 v7.3.7 正式版本。

当前提供 Intel（x64）安装包；Apple Silicon（M 系列）原生版正在构建和验证，完成后将添加到此发布。

适用 macOS 12 或以上。打开 DMG 后，将 ZL-WA 拖入 Applications（应用程序）；ZIP 为备用下载。已在 Intel macOS 环境验证安装后启动、界面和本地会话初始化，并核对 DMG/ZIP 内容、签名和 SHA256。

签名说明：此版本使用 ad-hoc 本地签名，没有 Apple Developer ID 签名和 Apple 公证。首次打开可能受到 macOS 安全检查拦截；仅在确认下载来源后，在“系统设置 → 隐私与安全性”中允许打开。

SHA256 校验值与构建验证报告见附件。
