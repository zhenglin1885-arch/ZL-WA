# ZL-WA 7.3.8 Windows 测试版 4

修复测试版 3 引入的普通消息接收翻译回归：之前排除群卡片时，额外要求消息具有旧类名或旧消息 ID，导致部分普通消息的“点击翻译”和自动翻译入口被误拦。

- 恢复普通消息的原有结构兼容，只排除可明确识别的名片、群资料和系统通知卡片。
- 验证四种不带旧气泡类名或旧消息 ID 的普通消息结构，确认手动按钮、请求提交及译文显示；自动接收预览也通过界面验证。
- Windows 安装包检查新增隔离页面中的普通消息实际翻译验证，同时确认名片、群资料卡片被排除。
- 保留测试版 3 的队列超时、手动优先、旧请求清理及测试版 2 的全零配置重建修复。

AutoSetup 为安装版，Portable 为免安装版。内部版本仍为 7.3.8，以本测试标签和诊断中的构建提交区分。此测试发布不替换正式版最新入口。
