# ZL-WA 7.3.9

Windows 与 macOS 使用同一份 7.3.9 源码同步发布。

- Windows：x64 安装版（AutoSetup）和免安装版（Portable）。
- macOS：Intel x64 与 Apple 芯片 arm64，分别提供 DMG 与 ZIP。

## 本次更新

- 账号侧栏和聚合会话分组支持鼠标拖动排序，重启后保留顺序；默认分组可移动。
- 客户 SABCD 标记采用金黄、红、蓝、绿、紫色，增加细轮廓，并显示在昵称后。
- 聚合会话显示名称、可直接编辑的红色备注、消息预览和所属账号；聊天顶部保留原生名称。
- 群内消息置顶保持 WhatsApp 官方行为，与聊天列表本地置顶隔离。
- 新消息声音增加独立兜底，音量提高至 85%，遵守静音与免打扰设置。
- 移动聚合会话分组前锁定本次选择，展示数量、名单和全选范围，降低误移风险。
- 新建群发任务按每个账号内所选群组列表从下往上发送，立即发送和定时发送均适用。
- Facebook Business 账号卡片增加登录状态检测：已登录绿点、未登录红点、加载或状态不明灰点。

## 验证与升级说明

发布流程要求 Windows 与两个 Mac 架构均完成类型检查、测试、打包及原生启动验证后，再统一公开正式版。Windows 另验证安装升级与恢复加载；Mac 校验 DMG、ZIP 内容一致性和签名。下载页附有 SHA256 校验值和验证报告。

建议先备份当前数据；免安装版继续使用原有 ZL-WAAppData 目录，以保留账号登录和设置。此前已发生的分组异常不会自动回滚，需结合备份或名单核对。
