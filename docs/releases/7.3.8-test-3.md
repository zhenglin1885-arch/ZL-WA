# ZL-WA 7.3.8 Windows 测试版 3

包含测试版 2 的配置重建修复，新增以下翻译修复：

- 修复“翻译队列繁忙，请稍后点击重试”可能持续不消失的问题：任务入队起设置两分钟总时限，到期取消请求并释放队列；页面未收到结果时也会回收过期名额，恢复手动重试。
- 手动点击的接收翻译优先于排队中的自动翻译，发送预览仍优先。Google 的节奏控制、并发限制及限流退避保留；服务本身不可用时仍会显示失败或超时，不能保证外部服务始终可用。
- 关闭或重新挂载翻译界面时清理旧请求，避免旧实例留下待处理状态；原生插入草稿前检查运行状态，迟到的结果不改写已取消的请求。
- 去掉群组加入、群资料及系统通知卡片中的翻译入口，名片过滤继续保留。普通文字、图片说明及引用卡片后的正常回复可继续翻译。

本地界面回归包含 Google 手动点击、关闭自动预览时，连续请求达到上限后超时释放并重新点击的场景。

AutoSetup 为安装版，Portable 为免安装版。内部版本仍为 7.3.8，请以测试标签和诊断中的构建提交区分。此测试发布不替换正式版最新入口。
