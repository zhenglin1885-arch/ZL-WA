# ZL-WA 7.3.10

Windows、Mac Intel 和 Mac Apple 芯片版本使用同一份源码发布。

- Windows x64：安装版 AutoSetup、免安装版 Portable。
- macOS Intel x64、Apple 芯片 arm64：各提供 DMG 和 ZIP。

## 本次更新

- 统一圆角、字体、间距与配色，完善浅色和深色主题。
- 客户标记、性别等选项增加边框和选中提示；群发、群组、进群、退群、点赞、回复窗口的选项、消息和执行结果分区更清晰。
- 新增分组与修改备注使用按钮下方的统一弹窗尺寸及间距。
- 浅色模式下，客户、代理和翻译面板使用独立底色；保留聊天区域尺寸。
- 修正小窗口下群发记录筛选栏和创建任务面板的横向溢出。
- 保留默认 Enter 发送与用户可选 Shift+Enter 发送设置，以及已验证的群发群组权限筛选和失败处理。

继续使用原有 WhatsApp 网页聊天界面与既有业务流程。
