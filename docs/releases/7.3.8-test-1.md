# ZL-WA 7.3.8 Windows 测试版 1

基于 7.3.8 的 Windows x64 测试包，包含以下待验证修复。此测试发布不替换正式版的最新发布入口。

- 修正特殊安装路径的界面地址编码，补齐主文档加载失败、缺少根节点或根节点隐藏时的恢复处理；界面在 DOM 就绪后初始化。
- Windows 任务栏右键新增 Reload UI 和 Restart without GPU。移动窗口、退出和恢复界面不再等待界面加载完成；软件渲染选项只影响本次重启。
- 托盘先于账号功能初始化。初始化失败时直接提供原生错误说明和 Export Diagnostics，不继续打开缺少代理或认证接口的半初始化界面，保留原配置和账号数据。
- 避免代理配置保存及测试时重复重置连接，改善 SOCKS5 慢协商超时和 HTTP/HTTPS 代理认证处理。线路本身不可用仍需更换或恢复代理服务。
- 名片不再显示翻译按钮，也不触发自动翻译；普通文本、图片说明和引用名片后的普通回复保留翻译。
- 重新翻译图标与译文末尾字符保持同行，改善短消息的翻译错误提示和自动源语言识别。
- 批量开关群遇到 WhatsApp 限流时按账号暂停和冷却，减少不必要的全量校验；已接受但状态尚未确认的操作不会立即重复提交。服务端限流无法通过客户端强制解除。

请优先在出现紫色空白的 Windows 11 电脑上测试普通启动。若仍异常，可测试任务栏右键的 Restart without GPU；如出现初始化错误窗口，请通过 Export Diagnostics 导出诊断。新增恢复入口不代表已经确认该电脑的具体故障原因。

AutoSetup 为安装版，Portable 为免安装版。保留原版号 7.3.8，请以本页面的测试标签和构建提交区分正式包。
