# ZL-WA 7.3.8 Windows 测试版 5

优化切换会话时“点击翻译”按钮及已有缓存译文的显示速度。

- 页面中的按钮和缓存恢复随消息 DOM 更新安排到下一帧，不再等待聊天切换稳定期和宿主定时扫描。
- 页面重载后批量读取可见消息的本地持久缓存，命中时无需经过网络翻译队列；自动翻译先检查缓存，再处理未命中的消息。
- 防止旧页面、旧聊天和旧语言设置的缓存结果覆盖当前会话，保留手动重译与自动翻译限速。
- 保留测试版 4 的普通消息翻译修复，以及之前的队列超时、配置重建与账户网络确认修复。
- Windows 打包验证增加离线页面中的按钮、缓存恢复及手动/自动翻译回归检查。

建议测试：反复切换已翻译会话，检查按钮及缓存译文的出现速度；重启后再次打开同一会话；确认手动重译和自动翻译仍可使用。

AutoSetup 为安装版，Portable 为免安装版。内部版本仍为 7.3.8，以测试标签和诊断中的构建提交区分。此测试发布不替换正式版最新入口。
