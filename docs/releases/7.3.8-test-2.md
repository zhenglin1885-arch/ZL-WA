# ZL-WA 7.3.8 Windows 测试版 2

包含测试版 1 的修复，并针对已确认的全零 `account-tools.json` 无法启动问题增加重建流程。

- 全零文件没有可恢复的原配置。若存在完整备份，优先提示恢复；没有有效备份时，逐字节另存原文件，再建立新配置，使主界面可以正常启动。
- 重建后各账号暂缓连接。请在右侧代理设置重新填写并点击“确认网络配置并应用”，再点击“重试加载会话”。不使用代理的账号也需要明确确认。只保存翻译设置不会解除网络限制。
- 原配置单独保存在原目录的 `account-tools.json.preserved-*`；不改写客户备注、登录资料和服务列表的其他文件。原代理、翻译设置及该配置文件中的历史记录无法从全零文件还原。
- 后续配置保存使用独立临时文件、落盘刷新和完整快照重命名，并保留上一份有效备份。兼容完整 JSON 的 Windows BOM 编码，诊断区分全零、空文件、格式、编码和读取错误。
- Windows 打包后启动检查使用与本次故障相同大小的人工全零文件，验证主界面启动、原文件保留、逐账号网络确认和重载。

AutoSetup 为安装版，Portable 为免安装版。内部版号仍为 7.3.8，请以本测试发布标签和诊断中的构建提交区分测试版。本发布不替换正式版最新入口。
